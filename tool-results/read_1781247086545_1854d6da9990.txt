    22→    22→## 1. Tổng Quan Kiến Trúc Mục Tiêu
    23→    23→
    24→    24→### Kiến trúc hiện tại (BROKEN):
    25→    25→
    26→    26→```
    27→    27→User Chat → /api/openclaw/chat
    28→    28→              ├── Code query? → OpenCode (port 18790) ← OK
    29→    29→              ├── Agent có provider+model? → ReAct loop:
    30→    30→              │     callLLMForAgent() → ❌ KHÔNG gửi tools
    31→    31→              │     parseToolCallsFromOutput() → ❌ Regex fragile  
    32→    32→              │     executeTool() → ❌ Chỉ 7 tools
    33→    33→              ├── Không có agent? → Gateway chatCompletion() → ❌ Không có NVIDIA key
    34→    34→              └── Fallback → /api/query → Local RAG
    35→    35→```
    36→    36→
    37→    37→### Kiến trúc mục tiêu (SAU P0):
    38→    38→
    39→    39→```
    40→    40→User Chat → /api/openclaw/chat
    41→    41→              ├── Code query? → OpenCode (port 18790) ← giữ nguyên
    42→    42→              │
    43→    43→              ├── Gateway ONLINE?
    44→    44→              │     └── YES → Route qua Gateway:
    45→    45→              │           POST /v1/chat/completions
    46→    46→              │           + Header: x-openclaw-model = agent.model
    47→    47→              │           + Body: tools = Gateway's 37 tools
    48→    48→              │           → Gateway tự handle ReAct loop
    49→    49→              │           → Trả về final response (đã xử lý tools)
    50→    50→              │           → ✅ 37 tools khả dụng
    51→    51→              │
    52→    52→              ├── Gateway OFFLINE?
    53→    53→              │     └── YES → Fallback local ReAct loop:
    54→    54→              │           callLLMForAgent() + tools parameter ← SỬA
    55→    55→              │           Parse structured tool_calls ← SỬA
    56→    56→              │           executeTool() (7 local tools + Gateway /tools/invoke) ← MỞ RỘNG
    57→    57→              │           → ✅ 7+ tools khả dụng
    58→    58→              │
    59→    59→              └── Cuối cùng → /api/query → Local RAG ← giữ nguyên
    60→    60→```
    61→    61→
    62→    62→### Chiến lược: Gateway-First, Local-Fallback
    63→    63→
    64→    64→- **Gateway online** → Route tất cả qua Gateway → 37 tools đầy đủ
    65→    65→- **Gateway offline** → Fallback local ReAct loop → 7+ tools (sửa đổi)
    66→    66→- **Không phá vỡ** flow hiện tại — chỉ thêm layer mới

    70→    70→## 2. Phát Hiện Quan Trọng Mới
    71→    71→
    72→    72→### ⚠️ HTTP Deny List — Thay đổi chiến lược P0
    73→    73→
    74→    74→Khi khảo sát Gateway API thực tế, phát hiện:
    75→    75→
    76→    76→**12+ tools quan trọng bị DENY qua HTTP `/tools/invoke`:**
    77→    77→```
    78→    78→exec, spawn, shell, fs_write, fs_delete, fs_move,
    79→    79→apply_patch, sessions_spawn, sessions_send, cron, gateway, nodes
    80→    80→```
    81→    81→
    82→    82→**Ý nghĩa:**
    83→    83→- Pattern B (Hybrid: gọi NVIDIA trực tiếp + execute tools qua `/tools/invoke`) **KHÔNG THỂ DÙNG** cho file/exec tools
    84→    84→- Chỉ có thể dùng `/tools/invoke` cho: `web_search`, `web_fetch`, `x_search`, `memory_search`, `memory_get`, `sessions_list`, `session_status`, `agents_list`, `message`
    85→    85→- **Pattern A (route qua Gateway `/v1/chat/completions`)** là con đường duy nhất để dùng tất cả 37 tools vì Gateway's internal agent loop không bị HTTP deny list
    86→    86→
    87→    87→### ✅ Gateway hỗ trợ model override per request
    88→    88→
    89→    89→- Header `x-openclaw-model` cho phép chỉ định model cho mỗi request
    90→    90→- Ví dụ: `x-openclaw-model: nvidia/qwen/qwen3.5-397b-a17b` → BOLT agent
    91→    91→- Không cần cấu hình mỗi agent riêng trong Gateway
    92→    92→
    93→    93→### ✅ Gateway đã có NVIDIA NIM built-in provider
    94→    94→
    95→    95→- Chỉ cần set `NVIDIA_API_KEY` env var → Gateway tự gọi NVIDIA NIM
    96→    96→- Dynamic model discovery từ `assets.ngc.nvidia.com` (cache 24h, max 32 models)
    97→    97→- App có thể dùng bất kỳ NVIDIA model nào thông qua `x-openclaw-model` header

   778→   778→/**
   779→   779→ * Validate tool schema theo OpenAI function calling format
   780→   780→ */
   781→   781→export interface SkillToolSchema {
   782→   782→  name: string
   783→   783→  description: string
   784→   784→  parameters: {
   785→   785→    type: 'object'
   786→   786→    properties: Record<string, {
   787→   787→      type: string
   788→   788→      description?: string
   789→   789→      enum?: string[]
   790→   790→      default?: unknown
   791→   791→    }>
   792→   792→    required?: string[]
   793→   793→  }
   794→   794→}
   795→   795→
   796→   796→export function validateToolSchema(schema: unknown): { valid: boolean; errors: string[] } {
   797→   797→  const errors: string[] = []
   798→   798→  
   799→   799→  if (!schema || typeof schema !== 'object') {
   800→   800→    return { valid: false, errors: ['Schema must be an object'] }
   801→   801→  }
   802→   802→  
   803→   803→  const s = schema as Record<string, unknown>
   804→   804→  
   805→   805→  if (!s.name || typeof s.name !== 'string') errors.push('Missing "name" field')
   806→   806→  if (!s.description || typeof s.description !== 'string') errors.push('Missing "description" field')
   807→   807→  if (!s.parameters || typeof s.parameters !== 'object') errors.push('Missing "parameters" field')
   808→   808→  
   809→   809→  return { valid: errors.length === 0, errors }
   810→   810→}

  1071→  1071→| Plugin sandbox escape | Security breach | Low | Dùng VM2; whitelist APIs; limit resources |
  1072→  1072→| Tool calling chậm (nhiều iterations) | UX kém | Medium | Timeout per iteration; streaming UI; max 5 iterations |
  1073→  1073→| NVIDIA rate limit (4 keys) | Agent không gọi được | Medium | Round-robin keys; exponential backoff; queue system |
