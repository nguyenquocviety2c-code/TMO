    22→## 1. Tổng Quan Kiến Trúc Mục Tiêu
    23→
    24→### Kiến trúc hiện tại (BROKEN):
    25→
    26→```
    27→User Chat → /api/openclaw/chat
    28→              ├── Code query? → OpenCode (port 18790) ← OK
    29→              ├── Agent có provider+model? → ReAct loop:
    30→              │     callLLMForAgent() → ❌ KHÔNG gửi tools
    31→              │     parseToolCallsFromOutput() → ❌ Regex fragile  
    32→              │     executeTool() → ❌ Chỉ 7 tools
    33→              ├── Không có agent? → Gateway chatCompletion() → ❌ Không có NVIDIA key
    34→              └── Fallback → /api/query → Local RAG
    35→```
    36→
    37→### Kiến trúc mục tiêu (SAU P0):
    38→
    39→```
    40→User Chat → /api/openclaw/chat
    41→              ├── Code query? → OpenCode (port 18790) ← giữ nguyên
    42→              │
    43→              ├── Gateway ONLINE?
    44→              │     └── YES → Route qua Gateway:
    45→              │           POST /v1/chat/completions
    46→              │           + Header: x-openclaw-model = agent.model
    47→              │           + Body: tools = Gateway's 37 tools
    48→              │           → Gateway tự handle ReAct loop
    49→              │           → Trả về final response (đã xử lý tools)
    50→              │           → ✅ 37 tools khả dụng
    51→              │
    52→              ├── Gateway OFFLINE?
    53→              │     └── YES → Fallback local ReAct loop:
    54→              │           callLLMForAgent() + tools parameter ← SỬA
    55→              │           Parse structured tool_calls ← SỬA
    56→              │           executeTool() (7 local tools + Gateway /tools/invoke) ← MỞ RỘNG
    57→              │           → ✅ 7+ tools khả dụng
    58→              │
    59→              └── Cuối cùng → /api/query → Local RAG ← giữ nguyên
    60→```
    61→
    62→### Chiến lược: Gateway-First, Local-Fallback
    63→
    64→- **Gateway online** → Route tất cả qua Gateway → 37 tools đầy đủ
    65→- **Gateway offline** → Fallback local ReAct loop → 7+ tools (sửa đổi)
    66→- **Không phá vỡ** flow hiện tại — chỉ thêm layer mới

    70→## 2. Phát Hiện Quan Trọng Mới
    71→
    72→### ⚠️ HTTP Deny List — Thay đổi chiến lược P0
    73→
    74→Khi khảo sát Gateway API thực tế, phát hiện:
    75→
    76→**12+ tools quan trọng bị DENY qua HTTP `/tools/invoke`:**
    77→```
    78→exec, spawn, shell, fs_write, fs_delete, fs_move,
    79→apply_patch, sessions_spawn, sessions_send, cron, gateway, nodes
    80→```
    81→
    82→**Ý nghĩa:**
    83→- Pattern B (Hybrid: gọi NVIDIA trực tiếp + execute tools qua `/tools/invoke`) **KHÔNG THỂ DÙNG** cho file/exec tools
    84→- Chỉ có thể dùng `/tools/invoke` cho: `web_search`, `web_fetch`, `x_search`, `memory_search`, `memory_get`, `sessions_list`, `session_status`, `agents_list`, `message`
    85→- **Pattern A (route qua Gateway `/v1/chat/completions`)** là con đường duy nhất để dùng tất cả 37 tools vì Gateway's internal agent loop không bị HTTP deny list
    86→
    87→### ✅ Gateway hỗ trợ model override per request
    88→
    89→- Header `x-openclaw-model` cho phép chỉ định model cho mỗi request
    90→- Ví dụ: `x-openclaw-model: nvidia/qwen/qwen3.5-397b-a17b` → BOLT agent
    91→- Không cần cấu hình mỗi agent riêng trong Gateway
    92→
    93→### ✅ Gateway đã có NVIDIA NIM built-in provider
    94→
    95→- Chỉ cần set `NVIDIA_API_KEY` env var → Gateway tự gọi NVIDIA NIM
    96→- Dynamic model discovery từ `assets.ngc.nvidia.com` (cache 24h, max 32 models)
    97→- App có thể dùng bất kỳ NVIDIA model nào thông qua `x-openclaw-model` header

   583→async function executeGatewayTool(name: string, args: Record<string, unknown>): Promise<unknown> {
   584→  const res = await fetch('http://127.0.0.1:18789/tools/invoke', {
   585→    method: 'POST',
   586→    headers: { 'Content-Type': 'application/json' },
   587→    body: JSON.stringify({ name, args }),
   588→    signal: AbortSignal.timeout(30000),
   589→  })
   590→  
   591→  if (!res.ok) {
   592→    throw new Error(`Gateway tool error: ${res.status}`)
   593→  }
   594→  
   595→  const data = await res.json()
   596→  if (!data.ok) {
   597→    throw new Error(`Tool error: ${data.error?.message || 'Unknown'}`)
   598→  }
   599→  
   600→  return data.result
   601→}

   610→  try {
   611→    let result: unknown
   612→

   614→    if (['opencode', 'knowledge_search', 'knowledge_graph', 
   615→         'knowledge_write', 'tavily', 'serper', 'jina'].includes(toolName)) {
   616→      // ... existing switch/case ...
   617→    }
   618→    
   619→    // 2. Thử Gateway tools (37 tools, chỉ HTTP-allowed ones)
   620→    else {
   621→      result = await executeGatewayTool(toolName, args)
   622→    }
   623→
   624→    return { success: true, result, duration: Date.now() - startTime }
   625→  } catch (err) {
   626→    // ...existing error handling...
   627→  }
   628→}

   775→**File mới:** `src/lib/skill-tool-schema.ts`

   777→```typescript
   778→/**
   779→ * Validate tool schema theo OpenAI function calling format
   780→ */
   781→export interface SkillToolSchema {
   782→  name: string
   783→  description: string
   784→  parameters: {
   785→    type: 'object'
   786→    properties: Record<string, {
   787→      type: string
   788→      description?: string
   789→      enum?: string[]
   790→      default?: unknown
   791→    }>
   792→    required?: string[]
   793→  }
   794→}
   795→
   796→export function validateToolSchema(schema: unknown): { valid: boolean; errors: string[] } {
   797→  const errors: string[] = []
   798→  
   799→  if (!schema || typeof schema !== 'object') {
   800→    return { valid: false, errors: ['Schema must be an object'] }
   801→  }
   802→  
   803→  const s = schema as Record<string, unknown>
   804→  
   805→  if (!s.name || typeof s.name !== 'string') errors.push('Missing "name" field')
   806→  if (!s.description || typeof s.description !== 'string') errors.push('Missing "description" field')
   807→  if (!s.parameters || typeof s.parameters !== 'object') errors.push('Missing "parameters" field')
   808→  
   809→  return { valid: errors.length === 0, errors }
   810→}
   811→```
